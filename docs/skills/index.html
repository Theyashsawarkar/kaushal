Skills

Every skill kaushal gives your agents: Claude Code on every account, Codex, opencode, Gemini CLI and any agent reading ~/.agents/skills. A skill is a folder with a SKILL.md: its description says when to use it, its body how. Ask an agent for the job in your own words and it uses the skill. Your own skills (kaushal new NAME) join these on your machine. Sources: skills/.

dsr

Write and send the user's Daily Status Report (DSR), the end-of-day email with a Time | Tasks table, for any date. Reconstructs the day from the user's git commits, matches the format of their past DSRs, checks the timetable (start and end time, lunch break, no gaps) and sends it as a real HTML table through sandesh, as a reply-all in their DSR thread. Use when the user asks for a DSR, daily status report, daily report, status mail or end-of-day update, or to send or backfill one for a date.
